# Brand asset provenance

`app-logo.png` was generated for this project with OpenAI's built-in ImageGen tool on 2026-08-28. No reference images were used. The transparent PNG is the single source for the Electron window, tray, renderer, packaging, and repository presentation.

Final prompt:

> Use case: logo-brand. Asset type: production desktop-app logo, tray icon, and small UI brand mark. Create one original abstract symbol for a network latency evidence tool. A single precise packet route should connect three compact nodes and rise into one decisive latency spike, communicating path diagnosis, correlation, and finding where lag begins. Premium vector-quality logo mark; flat geometric construction; restrained Swiss industrial design; deliberate negative space; crisp optical balance. One centered isolated mark inside a compact rounded-square graphite app tile; generous internal padding; strong silhouette; unmistakably legible at 16 px, 20 px, 32 px, and 256 px. Deep graphite `#0D1116`, signal cyan `#66BED9`, with at most one tiny diagnostic amber `#E1AD69` node. Genuinely transparent outside the rounded-square tile. No text, letters, initials, numbers, words, watermark, Wi-Fi fan, speedometer, globe, shield, generic heartbeat alone, stock network icon, gradients, mockup, 3D, perspective, reflections, bevels, shadows, or decorative clutter; exactly one isolated logo mark.
